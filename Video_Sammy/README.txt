Sammy: Screen Art Movie Maker — Design Summary
Concept
Sammy is a sibling to ScreenArt and SASS. It takes audio + images + transformers and produces a music video, driven by a Musart DSL — scripts that function as scores. Sammy reads ScreenArt's transformers as a library; transformer evolution stays in one place.
DSL shape
A Musart script has three regions: directives, configuration blocks, and a timeline.
@runtime 6:12
@fps 30
@audio ~/Audio/moog_piece.mp3
@output moog_piece.mp4
@compression hevc crf=30 preset=slow

@images { source: ~/ScreenArt/TransformedImages, filter: grade=A, shuffle: true }
@transformers { voronoi, kaleidoscope, oilpainting }

# Generative section
0:00..2:30 generative { slide_duration: 8s, crossfade: 1.5s }

# Scored section
2:30 image=mandala_042.jpg transformer=kaleidoscope(segments=12) duration=15s
2:45 crossfade 2s
2:47 image=lojong_017.jpg transformer=voronoi(cells=120) duration=20s
3:08 generative until=5:45 { slide_duration: 6s }
5:45 image=peace_003.jpg hold=until_end fade_out=3s
Generative and scored sections are first-class peers and freely interleavable. Time format accepts M:SS, M:SS.mmm, or bare seconds; internally everything is float seconds.
Parser strategy: don't write a real one. Use TOML/YAML for @directives and config blocks; bespoke line-oriented parsing only for the timeline (timestamp + verb + args).
Transformer parameters
Three forms, escalating in expressiveness:
rotation = 0.0                                          # constant
rotation = [(0.0, 0), (0.5, 180), (1.0, 360)]           # keyframes
rotation = [(0.0, 0), (0.5, 180), (1.0, 360)] @ pchip   # with interpolation mode
Keyframe times are normalized [0, 1] over the slide's duration by default, so animation curves are reusable across slides of different lengths.
Interpolation modes (all available via scipy.interpolate):

linear — interp1d(kind='linear') — predictable, kinked
pchip — PchipInterpolator — smooth, monotonic, never overshoots → good default
catmull — CubicSpline — smoothest, may overshoot
Named easing functions (ease_in, ease_out, ease_in_out) layered as time warps on top — orthogonal to interpolation choice

PCHIP is the right default: smooth but won't sneak in unrequested values like cells=125 when you wrote cells=80..120.
Implementation order
VersionCapabilityv0.1DSL parser, generative-only mode, static transformer params, single-image slides with ffmpeg xfade crossfadesv0.2Scored timeline blocks. The Music of Dreams video is hand-scoreable here.v0.5Animated parameters via keyframe lists. Linear interpolation only.v1.0PCHIP / Catmull-Rom / easing functions. Audio analysis (librosa) for driven_by=rms, driven_by=onset, etc.v2.0Per-segment interpolation modes, multiple driver curves, possibly MIDI input.
For the Music of Dreams piece specifically
You can ship it on v0.2: hand-scored timeline, static parameters, manual image selection. Animated parameters and audio reactivity are the cathedral; v0.2 is the campfire that gets the gift to your friend.
Technical foundations already settled

Reuse the x265 / crf=32 / tag=hvc1 encoding stack from record60s.sh.
ffmpeg filter graphs generated by Python; main job of the renderer layer is producing valid filter strings for variable slide counts.
Audio length is the master constraint — slide counts and durations derive from it, video length matches audio exactly.
Image selection respects ScreenArt's grading system; filter: grade=A is a natural first cut.

sample script:
@runtime 6:12
@fps 30
@output moog_piece.mp4
@audio ~/Audio/moog_piece.mp3
@compression hevc crf=30 preset=slow

@images {
  source: ~/ScreenArt/TransformedImages
  filter: grade=A
  shuffle: true
}

@transformers {
  voronoi(cells=80, blend=0.6)
  kaleidoscope(segments=8)
  oilpainting(radius=4)
}

# Generative section — pick images, apply random transformers, 8s slides
0:00..2:30 generative {
  slide_duration: 8s
  crossfade: 1.5s
  transformer_probability: 0.7
}

# Scored section — exact timing
2:30 image=mandala_042.jpg transformer=kaleidoscope(segments=12) duration=15s
2:45 crossfade 2s
2:47 image=lojong_017.jpg transformer=voronoi(cells=120, blend=0.8) duration=20s
3:07 crossfade 1s
3:08 generative until=5:45 { slide_duration: 6s }
5:45 image=peace_003.jpg hold=until_end fade_out=3s
